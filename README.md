# 製造現場のエラー情報蓄積・検索CLIツール

製造現場での機械や製品の不良・エラー情報を蓄積・検索するCLIツールです。

* 使用コード：error_log.c
* 使用ファイル：error_log.csv（CSV形式）

### 開発の背景
前職での経験から、夜勤帯などの孤立した現場や、初心者などのエラー対応において、手軽に過去のエラー情報を検索・蓄積して学べる環境を想定して設計しました。

### このツールの特徴
本ツールは、実際に前職でのエラー対応情報のデータ（一部架空のものに書き換えたもの）を使用しています。
キーボードから「機械名」や「製品名」などのキーワードを入力して検索することで、該当するエラーログや対応策を的確に抽出・表示できるツールです。
